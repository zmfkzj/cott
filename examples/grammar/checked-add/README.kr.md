# checked-add

## 예제 목적
더 넓은 반환형과 매니페스트에 연결된 Python 덧셈의 경계 관찰을 보여 줍니다.

## 핵심 포인트
- `checked_add`는 두 `I32`를 받아 `I64`를 반환합니다. `ensures` 절은 반환값을 `-4294967296`부터 `4294967294`까지로 제한하지만, 이 범위만으로 정확한 합을 확인하지는 못합니다.
- 시나리오는 양쪽 극단 입력 쌍의 정확한 결과를 관찰하여 해당 입력에서 상수 반환과 32비트 오버플로를 잡습니다. 다른 입력의 정확한 덧셈은 전수 검사되지 않습니다.
- `cott.toml`은 매니페스트 소유 Python 바인딩 `cott_bindings.curriculum.checked_add.checked_add:checked_add`를 유지하며, 선언된 오류 변형은 없습니다.
