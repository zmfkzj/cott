# cta-row

## 예제 목적
문자열·정수 입력을 enum과 명목 타입을 가진 대중교통 행으로 순서 있게 디코딩하는 예제입니다.

## 핵심 포인트
- `DayType` enum은 `U`·`A`·`W`를 각각 일요일·공휴일, 토요일, 평일 변형으로 매핑하고, 성공 값은 `RideRow`에 담깁니다.
- `RideRow`는 `RouteCode`, `ServiceDate`, `RideCount` 명목 타입과 `DayType`을 결합해 검증된 행을 표현합니다.
- 구현은 일 유형, 승차 수, 노선, 날짜 순으로 첫 오류를 반환하며, 노선은 숫자를 하나 이상 포함한 1~4자 ASCII 대문자·숫자이고 날짜는 유효한 `MM/DD/YYYY` 그레고리력 날짜여야 합니다.
