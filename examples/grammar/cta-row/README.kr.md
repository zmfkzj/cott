# cta-row

## 예제 목적
오류 우선순위와 시나리오로 관찰한 형식 경계를 따라 대중교통 행을 명목 타입으로 디코딩합니다.

## 핵심 포인트
- `RideRow`는 `RouteCode`, `ServiceDate`, `RideCount`, `DayType`을 결합합니다. 성공 형식 절은 노선·날짜 문자열을 보존하고 `U`, `A`, `W`를 각각 일요일·공휴일, 토요일, 평일 변형으로 매핑합니다.
- 조건부 절은 `InvalidDayType`을 `InvalidRidership`보다 먼저 요구합니다. 완전한 ASCII 노선·그레고리력 날짜 판정식을 계약 내장 함수로 표현할 수 없어 노선·날짜 오류는 조건 없이 선언합니다.
- 시나리오는 네 오류 우선순위, 노선 길이·숫자 경계, 윤년·0년 거부, 유효한 날짜와 요일 변형, 0·42·부호 있는 최대값의 정확한 승차 수를 관찰합니다. 모든 입력에서 노선·날짜의 유효성이나 승차 수 보존을 전수 확인하지는 못합니다.
