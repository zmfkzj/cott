# stock-record

## 예제 목적
사전조건을 요구하는 계산 함수와 원시 레코드를 검증해 위임하는 함수의 계약 분리를 보여 주는 예제입니다.

## 핵심 포인트
- `value_record`는 가격과 주식 수가 0 이상이라는 `requires`를 전제로 하며, 유한하지 않은 곱셈 결과만 `ValuationOverflow`로 반환합니다.
- `value_stock_record`는 이름, 주식 수, 가격을 검증한 뒤 유효한 `StockRecord`를 `value_record`에 전달하고 성공 값이 0 이상임을 보장합니다.
- 구현의 오류 우선순위는 빈 이름, 음수 주식 수, 비유한 가격, 음수 가격이며, 그 다음에 평가 오버플로를 검사합니다.
