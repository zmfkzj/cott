Effect implementations must use genuine Kotlin/JDK APIs and return the generated cott_runtime.Ok or cott_runtime.Err values with the exact generated EffectError variants. Never define replacement fixture types, simulate SQLite with a plain file, or return a blanket error without attempting the declared operation.
Scenario expressions resolve files.path(...) and service.url(...) before facade invocation: effect callables receive the resulting java.nio.file.Path or loopback URL String directly. CottRuntime.fixturePath/fixtureUrl and their suspend forms are runner lookup APIs, not file, network, clock, failure, database, random, or process-operation hooks.
read_text must decode UTF-8; copy_text must stage a sibling temporary file and atomically replace the destination without deleting the old destination first; fetch_local must use a JDK HTTP client that follows redirects and must reject an empty URL. store_and_load must use a real SQLite JDBC connection for the supplied database Path. sample_index must be deterministic from seed and strictly below limit. exit_with_code must terminate with the supplied unsigned code.
clock_ns requires the compiler-owned deterministic clock named by the contract. The current Kotlin runtime exposes no such public operation hook; do not substitute System.nanoTime, System.currentTimeMillis, a constant, or reflective/private access.
