# archive-request

## 예제 목적
보관 요청의 URL과 캡처 선택을 검증해 결정적인 보관 계획을 만듭니다.

## 핵심 포인트
- HTML과 미디어를 모두 선택하지 않으면 URL을 해석하기 전에 `EmptySelection`을 반환합니다. 선택된 경우에만 HTTP·HTTPS URL을 정규화합니다.
- 정규화는 스킴과 호스트만 소문자로 바꾸고 사용자 정보·포트·경로·쿼리·프래그먼트는 보존합니다. 유효하지 않은 퍼센트 이스케이프와 잘못된 URL은 `InvalidUrl`입니다.
- 두 캡처를 모두 요청하면 계획의 캡처 순서는 항상 HTML, 미디어입니다.
