# decimal-binary

## 예제 목적
음수가 아닌 I64 십진수와 이진 문자열을 서로 변환하는 예제입니다.

## 핵심 포인트
- `Conversion`과 `ConversionResult` 태그 열거형이 십진수→이진수와 이진수→십진수 요청·결과를 하나의 진입점에서 구분합니다.
- 십진수 변환은 0을 `"0"`으로, 다른 값은 앞자리 0 없는 최단 이진수로 반환하고 음수는 `NegativeDecimal` 오류로 처리합니다.
- Python 구현은 이진 문자열 전체를 먼저 ASCII `0`/`1`인지 검증해 잘못된 문자가 오버플로보다 우선하며, 앞자리 0을 뺀 유효 자릿수가 63개를 넘으면 `Overflow`를 반환합니다.
