# decimal-binary

## 예제 목적
두 변환 함수와 태그가 있는 합성 함수를 통해 음수가 아닌 I64 십진수와 이진 문자열을 변환합니다.

## 핵심 포인트
- `decimal_to_binary`는 음수에 `NegativeDecimal`을 명시하고 0의 결과를 `"0"`과 연결하며, 그 외 음수가 아닌 값의 최단 ASCII 이진 표현은 `doc`에 정의합니다.
- `binary_to_decimal`의 `doc`은 비어 있지 않은 ASCII 입력, 선행 0, 63개 유효 자릿수 초과보다 잘못된 문자가 우선한다는 규칙을 정의합니다. 입력 전체에 걸친 이 판단은 여기서 조건부 오류로 표현되지 않아 선언된 오류와 시나리오 증거로 남습니다.
- `convert_binary_decimal`의 `doc`과 연결된 요구사항은 선택한 공개 변환 함수, 결과 태그, 변형 없는 오류 전파를 명시합니다.
- 시나리오는 0, 6, 선행 0, I64 최댓값, 오버플로, 잘못된 문자 우선순위, 두 합성 경로와 오류를 구체적으로 관찰합니다. 이 검증 스냅샷의 세 요구사항은 `observed`이지 증명되지 않았으며, 검사하지 않은 입력과 내부 파사드 호출 의무까지 빠짐없이 확립하지는 않습니다.
