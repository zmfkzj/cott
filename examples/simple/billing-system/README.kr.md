# billing-system

## 예제 목적
의료·식료품·음료 품목을 검증하고 카테고리별 세금이 포함된 청구 합계를 계산하는 예제입니다.

## 핵심 포인트
- `BillingItem`, `Quantity`, `BillTotals`로 품목·수량·카테고리별 소계와 세금을 타입 계약으로 표현합니다.
- 검증은 음수 수량, 전체 목록의 중복 품목, 잘못된 카테고리 순으로 완전한 패스를 수행하며 0 수량도 중복 검사에 포함합니다.
- Python 구현은 센트 정수로 소계와 5%/10% 세금을 계산하고, 동점은 짝수 센트로 반올림한 뒤 F64 금액으로 반환합니다.
