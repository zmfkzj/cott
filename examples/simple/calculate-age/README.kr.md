# calculate-age

## 예제 목적
기준 날짜와 만 나이에서 그레고리력 경과 일수와 나이 요약을 계산하는 예제입니다.

## 핵심 포인트
- `calculate_age_days`는 음수 나이, 잘못된 날짜, 오버플로를 우선순위에 따라 `AgeError`로 반환합니다.
- 2월 29일 기준일은 비윤년의 시작 연도에서 2월 28일 기념일로 조정해 윤년 경계를 다룹니다.
- `summarize_age`는 보조 함수의 오류를 그대로 전파하고, 이름·연수·월수(`years * 12`)·경과 일수를 `AgeSummary`로 묶습니다.
