# calculator

## 예제 목적
두 binary64 수에 사칙연산과 거듭제곱을 적용하면서 부동소수점 오류를 구분하는 예제입니다.

## 핵심 포인트
- `CalculatorOp`가 덧셈·뺄셈·곱셈·나눗셈·거듭제곱을 제한하고, 결과 또는 `CalculatorError`를 `Result`로 반환합니다.
- 검증은 NaN/무한대, 부호 있는 0으로 나누기, 0의 음수 지수와 음수 밑의 비정수 지수를 차례로 거부합니다.
- Python 구현은 유한 입력으로 생긴 무한 결과나 `math.pow` 오버플로를 `Overflow`로 바꾸며, 언더플로와 부호 있는 0은 유효 결과로 유지합니다.
