# tic-tac-toe

## 예제 목적
3×3 틱택토 보드에 한 수를 안전하게 적용하고 게임 상태를 판정하는 예제입니다.

## 핵심 포인트
- `Cell`, `Player`, `Outcome` 열거형과 `MoveResult` 구조체로 보드·다음 차례·결과를 명시적으로 전달합니다.
- Python 구현은 9칸 길이를 먼저, 위치 범위를 다음으로 검증한 뒤 X/O 개수와 승리 일관성을 확인합니다.
- 위치 범위, 차례, 종료된 게임, 이미 둔 칸을 정해진 우선순위로 `Result` 오류로 구분하고, 성공 시 새 보드를 만들어 반환합니다.
