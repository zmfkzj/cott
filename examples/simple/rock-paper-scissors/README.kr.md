# rock-paper-scissors

## 예제 목적
가위바위보의 두 수를 입력받아 승패를 순수하게 판정하는 예제입니다.

## 핵심 포인트
- `RpsMove`와 `RoundResult` 열거형으로 가능한 입력과 사용자 승리·컴퓨터 승리·무승부 결과를 닫힌 집합으로 모델링합니다.
- `user_beats_computer`는 바위-가위, 보-바위, 가위-보의 세 승리 관계만 `true`로 반환합니다.
- `decide_round`는 같은 수를 먼저 무승부로 처리하고 보조 함수를 재사용하므로 난수 선택이나 입출력 없이 판정 규칙만 학습할 수 있습니다.
