# compute-iou

## 예제 목적
두 inclusive-pixel 경계 상자의 교집합 대비 합집합 비율(IoU)을 계산하는 예제입니다.

## 핵심 포인트
- `Box` 좌표와 `IntersectionUnion` 면적을 분리해 정수 면적 계산과 F64 비율 계산의 경계를 명확히 합니다.
- 너비와 높이는 `max - min + 1`이고 겹치지 않는 상자의 교집합 차원은 0으로 제한하므로 IoU는 0.0이 됩니다.
- Python 구현은 정답 상자, 예측 상자, 면적 오버플로, 0 합집합 순으로 검증하고, 성공한 IoU가 유한한지 확인합니다.
