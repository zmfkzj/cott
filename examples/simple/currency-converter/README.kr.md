# currency-converter

## 예제 목적
EUR 기준 환율 목록으로 통화 금액을 변환하고 입력·반올림 경계를 처리하는 예제입니다.

## 핵심 포인트
- `ConversionRequest`는 수량, 출발·도착 통화, EUR당 환율을 하나의 타입 계약으로 묶고 `Rate` 코드는 정확히 세 ASCII 대문자여야 합니다.
- 검증은 유한·음수가 아닌 수량, 양의 유한 환율, 중복과 누락 없는 출발·도착 환율을 정해진 오류 우선순위로 검사합니다.
- Python 구현은 출발 환율로 나눈 뒤 도착 환율을 곱하고, 같은 통화도 전체 환율 목록을 검증한 후 반올림하며, 센트 동점은 짝수로 반올림합니다.
