# alphabetical-file-groups

## 예제 목적
파일명 첫 Unicode 코드 포인트로 폴더를 선택하고, 입력 순서대로 분류 결과를 합성합니다.

## 핵심 포인트
- `classify_filename`은 원본 파일명 보존을 정형 절로 명시하고 빈 파일명일 때 정확히 `EmptyFilename`을 요구합니다. 폴더 규칙은 `doc`에서 선두 글자의 전체 Unicode case fold 또는 비문자일 때 `misc`로 정의합니다.
- `group_filenames`는 성공 시 입력마다 한 이동 항목, 첫 오류 전파, 순서와 중복 보존을 명시합니다. 목록 전체의 오류 조건과 항목별 순서는 절로 표현하지 못하여 시나리오로 관찰합니다.
- 시나리오는 ASCII, `ß`→`ss`, `İ`→`i̇`, 비문자, 빈 파일명, 순서가 있는 중복 이동, 앞선 오류를 관찰합니다. 이 검증 스냅샷의 두 요구사항은 `observed`이지 증명되지 않았으며, 전체 Unicode 대응표와 실제 내부 호출 순서까지 빠짐없이 검사하지는 않습니다.
