# textfile-analysis

## 예제 목적
Unicode 텍스트의 줄·문자·단어·특수문자 통계를 한 구조체로 계산하는 예제입니다.

## 핵심 포인트
- `TextAnalysis`는 전체 줄, 공백을 제외한 문자, 단어, 고유 단어, 특수문자 수를 각각 U64 필드로 반환합니다.
- 단어 추출은 대소문자 폴딩 뒤 Unicode 영숫자의 최대 연속 구간만 사용하며, NFKC 정규화를 하는 `unique-words` 예제와 다릅니다.
- Python 구현은 줄 구분자로 U+000A만 세고, 영숫자도 공백도 아닌 코드 포인트만 특수문자로 셉니다.
